Job Intake API
← Back to appopenapi.json

Local REST API for searching, ranking and tracking jobs. Every job carries a match score (0–100) against your profile plus human-readable reasons. Write requests need Content-Type: application/json. If the server was started with --token, send Authorization: Bearer <token>.

For Claude, the MCP server is easier: claude mcp add jobintake -- python3 ~/jobintake/jobintake.py mcp
